# WeaveXDR 아키텍처

## 실시간 보안 이벤트 경로

`SysmonCollector`는 Windows Event Log API에서 현재 마지막 레코드 이후의 이벤트 ID 1·3·11만 폴링한다. 원본 XML은 `SysmonXmlParser`에서 공통 이벤트로 정규화되고 ProcessGuid 기반 사건 ID로 묶인 뒤 `PersistentIngestionService`를 통해 중복 제거·SQLite 저장·실행 그래프 분석·대시보드 알림으로 전달된다.

포터블 EXE는 일반 사용자 수집기를 함께 시작하고 종료 시 작업 스레드를 먼저 정리한다. 권한이 부족하면 인증된 대시보드 요청이 Windows UAC를 열고, 내장 스크립트가 현재 사용자에게 Sysmon 채널 읽기 `0x1`만 추가한다. 설치형 Windows 서비스는 LocalSystem 컨텍스트에서 동일 수집기를 사용한다. 로그 누락·권한 부족·모듈 오류는 서버를 중단하지 않고 상태 API에 표시하며 자동 재시도한다.

## 조사 시각화

대시보드는 사건의 `Host → Process → File/IP` 관계를 SVG 엔티티 그래프로 표현한다. Sysmon 네트워크 이벤트는 소스·목적지 주소와 연결 방향을 보존하여 인바운드와 아웃바운드를 구분한다. IP 지도는 현재 로컬 추정 데이터만 사용하며, 확인되지 않은 주소를 임의의 국가로 단정하지 않고 GeoIP 데이터 연동 필요 상태로 표시한다.

시각 체계와 반응형 검증 기준은 [UI_DESIGN.md](UI_DESIGN.md)를 따른다.

## 보안 지식 그래프

실행 그래프는 현재 사건을 분석하는 작업 흐름이고, 보안 지식 그래프는 여러 사건에서 반복되는 대상과 관계를 장기 조회하는 저장 구조다. 두 그래프는 서로 대체하지 않는다.

현재 백엔드는 별도 서버가 필요 없는 SQLite 속성 그래프다. `Host`, `User`, `Process`, `File`, `IP`, `Alert` 노드와 `RUNS`, `EXECUTES`, `SPAWNED`, `CREATED`, `CONNECTED_TO`, `OBSERVED` 관계를 저장한다. 사용자 이름은 원문 대신 로컬 salt로 만든 단방향 식별자만 저장한다.

사건 보고서 변환 파이프라인은 다음 기능을 제공한다.

- 동일 엔티티가 겹치는 과거 유사 사건 순위 조회
- 제한된 hop 수의 공격 경로 조회
- 같은 프로세스의 파일 생성과 공인 IP 연결을 묶는 그래프 탐지
- 노드·엣지·DB 크기 측정과 저장 백엔드 재평가

개인용 단일 호스트 환경에서는 운영과 복구가 단순한 SQLite를 유지한다. 기본 기준인 노드 100만 개 이상 또는 실제 조회 지연이 허용 범위를 넘을 때만 전용 그래프 DB를 검토한다.

### GraphRAG 판단

키워드 검색과 공유 엔티티 기반 그래프 검색을 같은 기대 사건으로 비교하는 실험기를 제공한다. 표현이 달라도 IP·파일·프로세스가 겹치는 사건은 그래프 검색이 찾을 수 있다. 현재 MVP는 근거 사건 ID 반환이면 충분하므로 생성형 LLM을 추가하지 않고 그래프 검색만 사용한다. 실제 평가에서 그래프 검색의 recall 개선이 없으면 키워드 검색을 유지하고 증거 데이터를 먼저 보강한다.
