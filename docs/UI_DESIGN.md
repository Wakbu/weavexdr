# WeaveXDR UI 설계 기준

## 사건 관리와 그래프 조사

사건 큐는 신규·조사 중·보류·해결·오탐 상태, 메모·태그·북마크·체크리스트, 사용자 제목과 저장된 검색을 제공한다. 영구 삭제는 사건 ID를 다시 입력해야 하며 오탐은 탐지를 즉시 비활성화하지 않고 검토 후보로 남긴다.

관계도는 계층·방사·시간축 레이아웃, 유형별 접기, 미니맵, 시간 슬라이더, 위험 경로 강조와 공격 단계 마커를 제공한다. 노드 우클릭 과거 사건, 화살표 키 이동, PNG·SVG·JSON 내보내기를 지원하며 레이아웃·유형·위험 필터는 사건별로 저장된다.

## 참고한 조사 흐름

- Microsoft Defender XDR: 사건 그래프에서 사용자, 장치, 프로세스, 파일과 IP를 연결하고 노드 선택 시 상세 정보를 연다.
- Palo Alto Cortex XDR: 원인 프로세스부터 후속 실행·파일·네트워크 행위를 인과관계 체인으로 보여준다.
- Bitdefender XDR: 활동 패널, 그래프, 엔티티 상세를 한 조사 흐름으로 묶고 진입점과 이탈 지점을 구분한다.
- Kaspersky XDR: 경보와 공통 엔티티의 관계를 조사 그래프로 표현한다.
- 알약 XDR: 엔드포인트·네트워크 등 여러 영역의 이벤트를 연결해 다단계 공격 전체 맥락을 제공한다.
- 사용자 learning-flow: 검색·범주 필터·연결선·선택 노드 상세 패널을 한 화면에 배치한다.

## 현재 시각 원칙

- 흑연색 기반의 중성 표면과 얇은 구분선을 사용하고 상태색은 위험·경고·정상 의미에만 쓴다.
- 둥근 카드와 장식용 그라데이션을 반복하지 않는다.
- 개요는 `신호 요약 → 공격 관계도/지도 → 추이 → 사건 큐` 순서로 읽힌다.
- 조사 화면은 `사건 헤더 → 관계도 → 선택 엔티티 → 위치/검증/출처` 순서를 유지한다.
- 네트워크 방향을 확인할 수 없는 이벤트는 유입으로 단정하지 않는다.
- GeoIP 데이터가 없는 주소는 임의 국가 대신 `GeoIP DB 미연동`으로 표시한다.
- 조사 관계도는 노드 이동, 빈 공간 드래그 이동, 휠·버튼 확대/축소, 초기화와 엔티티 검색을 지원한다.
- 관계도를 다시 그려야 할 때도 사용자가 조정한 노드 위치와 화면 배율은 사건별 세션 상태로 보존한다.
- 사건 활동 목록과 MITRE ATT&CK 전술·기술 표시는 관계도와 같은 조사 영역 안에서 연결해 보여준다.

## 부분 갱신 원칙

- 주기적 상태 확인은 수집기 상태 영역만 갱신하고 설정·사건·관계도 화면 전체를 다시 만들지 않는다.
- 실시간 사건 수신은 지표, 추이, 사건 표와 실제로 변경된 사건의 조사 패널만 갱신한다.
- 개요 관계도와 IP 지도는 최신 사건의 ID·이벤트 수·최종 시각이 달라졌을 때만 다시 그린다.
- 사용자가 드래그한 노드 위치, 확대 배율, 선택한 조사 탭 같은 상호작용 상태는 데이터 갱신과 분리한다.
- 새 주기 갱신 기능을 추가할 때는 데이터 요청과 DOM 갱신 대상을 별도 함수로 나누고 전체 화면 렌더 호출을 재사용하지 않는다.

## 일반 사용자 인증 UI

- 포터블 EXE 대시보드에는 토큰 또는 고정 인증 정보 입력란을 표시하지 않는다.
- EXE가 연 브라우저 주소에서 자동 세션 교환을 완료하고 인증 정보는 주소와 JavaScript 메모리에서 즉시 제거한다.
- 자동 연결 실패 화면은 임의 값 입력을 요구하지 않고 EXE 재실행과 자동 재시도만 안내한다.
- 기본 포트가 사용 중이면 EXE가 빈 loopback 포트를 선택하며 설정 화면은 고정값이 아닌 현재 주소를 표시한다.

## 시각 검증 기준

- 기본 데스크톱, 900px, 640px 너비에서 본문 가로 넘침이 없어야 한다.
- 좁은 화면의 큰 그래프는 글자를 축소하지 않고 그래프 영역만 가로 스크롤한다.
- 페이지 전환 시 스크롤을 상단으로 복원한다.
- 텍스트 잘림, 패널 겹침, 비정상적인 빈 공간과 브라우저 오류를 실제 EXE에서 확인한다.
- 외부 사례의 화면을 그대로 복제하지 않고 정보 구조와 조사 흐름만 참고한다.
- 주요 본문과 조작 텍스트는 데스크톱 기준 11px 미만으로 축소하지 않고, 작은 화면에서는 글자 축소보다 패널 재배치를 우선한다.
- 관계도 SVG 글자는 노드의 고정 폭과 실제 패널 축소율을 함께 고려해 제목 13px, 보조 정보 10~10.5px 수준을 기준으로 하며 텍스트가 노드 밖으로 시각적으로 확장되지 않게 한다.
- 관계도 말줄임은 글자 수가 아니라 실제 렌더링 픽셀 폭으로 계산하고 전체 값은 노드 툴팁에 보존한다.
- 같은 단계의 노드는 세로 7개 단위로 보조 열에 배치해 서로 겹치지 않게 한다. 조사 화면은 대형 그래프 전체를 억지로 축소하지 않고 읽을 수 있는 기본 배율과 이동·확대 탐색을 사용한다.
- 조사 그래프의 미니맵은 본문 SVG와 별도 크기 규칙을 사용하고 포인터 입력을 받지 않는다. 본문은 실제 컨테이너 폭으로 좌표를 계산하며 확대·축소·초기화 컨트롤은 그래프 안에서 넘치지 않는다.
- 외부 연결 지도는 공개 도메인 Natural Earth 1:110m 국가 경계를 내장하고 경도·위도를 동일한 투영식으로 배치한다. 한국과 일본을 포함한 실제 국가 윤곽을 분리해 표시하며 확인되지 않은 IP의 국가는 임의로 추정하지 않는다.
- 선택·키보드 포커스는 고정 노드 사각형의 색과 선 두께만 바꾸고 브라우저 기본 SVG 외곽선처럼 경계 크기가 달라지는 표현을 사용하지 않는다.
- 전체 사건 목록은 서버에서 기본 50건 단위로 나누고 사용자가 100건 단위를 선택할 수 있게 한다. 검색·필터 변경 시 첫 페이지로 돌아가며 전체 KPI는 현재 페이지 행 수와 분리한다.
- 사건 제목은 내부 ID가 아니라 `행위 + 핵심 프로세스·파일·IP` 형식의 짧은 한국어 문장으로 표시하고 전체 ID는 보조 줄에 둔다.
- `weavexdrUiDiagnostics()`는 현재 화면의 가로 넘침, 잘린 입력·버튼, 11px 미만 텍스트, 그래프 조작부와 포커스 가능 항목 수를 반환한다.
- `scripts/validate_ui_contract.py`는 중복 ID, 필수 반응형 분기, 최소 조작 높이, 키보드 그래프·지도·아이콘 계약과 640·900·1280·1920px × 100·125·150% 검증 매트릭스를 CI에서 검사한다.
- 같은 검사는 정적 입력 컨트롤의 연결된 레이블 또는 `aria-label`과 본문·보조 텍스트의 WCAG AA 대비도 확인한다.

# 파일 검사와 탐지 콘텐츠 화면

파일 검사 페이지는 프로필, Windows 기본 파일·폴더 선택창, 선택 경로 목록, 검사
진행률, 취소와 격리 재검사 복원을 한 흐름으로 제공한다. 사용자가 경로 문자열을
직접 편집하지 않으며 여러 번 선택한 경로는 중복 없이 누적하고 한 번에 지울 수 있다.
설정 화면의 탐지 콘텐츠 카드는 Sigma YAML 후보를 검증하되
기본 비활성 상태를 명시하고 외부 평판 전송 동의가 없음을 함께 알린다.

모든 입력창·셀렉트·텍스트 영역·버튼은 공통 높이, 테두리, 포커스와 간격을 사용한다.
파일 검사는 새 검사와 진행 상태를 2열로 배치하고 축소 화면에서는 1열로 전환한다.
동적 사건 관리 폼도 각 컨트롤 위에 명시적 레이블을 배치한다.

# 최근 의심 징후 3D 지구본

보안 개요의 공격 관계도와 외부 연결 위치 위에는 Natural Earth 국가 경계를 로컬
캔버스에 구면 투영한 3D 지구본을 배치한다. 캔버스는 CSS 크기와 화면 배율에 맞춘
내부 해상도와 2160×1080 지도 텍스처를 사용하며 데스크톱에서 480~560px 높이를
확보해 구체가 타원으로 늘어나거나 눌리지 않게 한다. 기본 시점과 홈 버튼은 대한민국
중심이고 자동 회전은 사용하지 않는다. 포인터 드래그로 위도·경도를 회전하고 휠 또는
`−·⌂·＋` 버튼으로 확대·축소·초기화한다.

사용자가 최근 1·6·24시간, 7·30일을 선택하면 사건 갱신 시각을 기준으로 고위험·검토
필요 사건을 판정별 최대 100개까지 읽어 공격 확정 여부와 무관하게 탐지된 징후를
국가별로 집계한다. 현재 집계 기준은 선택기 옆에 항상 표시한다. 로컬 프로세스·파일 징후는 `대한민국 · 보호 단말
기준`으로 표시하고, 원격 위치는 수집 이벤트 또는 로컬 GeoIP에서 확인된 경우에만
표시한다. Natural Earth 지도에서 보호 기준점은 대한민국만 강조하며 일본은 일반 국가
스타일을 유지한다. 같은 사건에서 연쇄된 위치는 점선으로 연결한다. 위치 미확인·내부망·Anycast
주소는 지구본에 임의 배치하지 않는다. 점과 국가 버튼을 누르면 해당 위치와 연결된
사건 목록을 열고, 그 사건 ID 집합만 사건 큐에서 임시 지도 필터로 확인할 수 있다.
상세 목록은 지구본 회전·확대 입력과 분리된 내부 스크롤 영역을 사용한다. 목록 제목,
닫기 버튼 또는 사건 행 위에서 휠을 움직여도 같은 목록이 이동하며 방향키·Page Up/Down·
Home·End도 지원한다. 스크롤바는 목록 영역 안에만 표시하고 브라우저 기본 화살표가
패널 모서리 밖으로 돌출되지 않게 한다.

지구본, 개요·조사 공격 관계도, 개요·조사 위치 지도, 최근 사건과 사건 큐 표에는
`⛶` 전체 화면 버튼을 제공한다. 전체 화면에서도 그래프·지도 높이를 화면에 맞추고
Escape 또는 같은 버튼으로 원래 배치에 돌아온다.

파일 검사 진행 카드는 파일 목록을 만드는 동안 발견 파일 수와 현재 폴더를 표시한다.
실행 중에는 새 검사 버튼을 비활성화하고 서버도 중복 요청을 거부하며, 완료·실패·취소
후에는 다른 경로로 새 검사를 즉시 시작할 수 있어야 한다.

# 시작 화면·사이드바 경계·AI 도우미 상태

사이드바 접기 손잡이는 별도 탭처럼 보이는 짧은 버튼이 아니라 사이드바 오른쪽 경계를
위에서 아래까지 잇는 12px 일자 패널로 사용한다. 화살표는 세로 중앙에 놓고 호버할 때만
폭과 경계색을 조금 강조해 본문과 겹치는 시각적 덩어리를 만들지 않는다.

최초 데이터 로딩 중에는 완성 전 KPI와 배너를 노출하지 않고 전체 화면을 암전한 뒤 로고,
진행선과 상태 문구만 표시한다. 자체 보호 알림은 보안 개요에서만 보이며 변경·누락·추가
수를 먼저 요약하고 펼침 영역에서 영향 파일을 유형별로 확인한다.

Weave AI 캐릭터는 사람 얼굴 대신 둥근 머리, 작은 귀와 은은한 볼터치를 가진 펫형
실루엣을 사용하며 고정된 웃는 얼굴을 반복하지 않는다. 느린 유휴 움직임과 불규칙한 눈
깜빡임을 기본으로 하고 열기, 답변 생성, 정상 완료와 규칙 대체 상태를 표정과 움직임으로
구분한다. 사용자가 동작 감소를 요청한 환경에서는 모든 반복 애니메이션을 중단한다.
답변 생성 중에는 입이 회전하지 않고 위쪽을 바라보는 눈, 기울어진 작은 입과 생각 방울로
고민 상태를 표현한다. 런처는 포인터로 화면 안에서 이동할 수 있으며 위치를 로컬에 저장하고
창 크기가 바뀌면 보이는 영역 안으로 다시 제한한다. 대화 패널은 이동한 런처 가까이에 연다.

# 사용자 화면 설정과 도움말

상단 정보 밀도 선택은 `간단히·기본·조밀하게·상세`를 제공하고 같은 브라우저에서 유지한다.
사건 표는 판정·주요 증거·발생 시각 열을 선택적으로 숨기고 균형형·요약 중심·증거 중심
너비를 고를 수 있으며 위험도와 사건 제목은 항상 남긴다. 좁은 화면에서는 표 전체를
찌그러뜨리지 않고 내부 가로 스크롤을 사용한다.
경로·명령줄·탐지 근거처럼 긴 값은 셀 경계에서 줄바꿈한다.

모든 화면의 `?` 버튼은 현재 화면의 목적, 우선 확인 항목과 안전 제약만 짧게 설명한다.
위험 작업은 기존 확인 절차를 유지하고 도움말이 승인 절차를 대신하지 않는다.

사이드바를 접으면 콘텐츠 최대 폭 제한을 해제해 넓어진 영역을 그래프·표·설정 카드가
실제로 사용한다. 사건 열 선택 항목은 한글 단어를 두 줄로 쪼개지 않고 한 줄로 표시한다.
