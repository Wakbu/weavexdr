# WeaveXDR

> 내 컴퓨터에서 무슨 일이 일어났는지 모아 보고, 수상한 행동이 서로 어떻게 연결됐는지 쉽게 보여 주는 Windows 보안 프로그램입니다.

WeaveXDR은 어려운 보안 로그를 사람이 읽을 수 있는 **사건**으로 정리합니다. 예를 들어 어떤 프로그램이 실행되고, 그 프로그램이 파일을 만들고, 이어서 외부 인터넷 주소에 접속했다면 이 행동들을 하나의 흐름으로 연결해 보여 줍니다.

모든 분석의 중심은 내 PC입니다. 사건과 설정은 로컬에 저장되고, 로컬 AI 기능도 사용자가 직접 설치·선택한 경우에만 보조 설명을 만듭니다.

## 아주 쉽게 말하면

집에 CCTV가 여러 대 있다고 생각해 보세요.

- **Windows와 Sysmon**은 방마다 설치된 카메라처럼 프로그램 실행, 파일 생성, 네트워크 연결을 기록합니다.
- **WeaveXDR**은 흩어진 영상을 시간순으로 모아 “이 행동과 저 행동이 같은 사건입니다”라고 정리합니다.
- **탐지 규칙**은 미리 정한 안전 수칙입니다. 이상한 명령, 수상한 실행 경로, 여러 단계로 이어진 행동을 찾습니다.
- **관계도**는 사건에 등장한 프로그램·파일·IP 주소를 점과 선으로 연결한 지도입니다.
- **로컬 AI**는 조사 내용을 쉬운 말로 설명하는 보조자입니다. 혼자서 파일을 지우거나 차단하지 않습니다.

WeaveXDR은 백신을 완전히 대신하는 제품이 아닙니다. 기존 Microsoft Defender와 함께 사용하면서 “무슨 일이 연결되어 있었는지” 조사하는 도구에 가깝습니다.

## 처음 사용하는 방법

1. [GitHub Releases](https://github.com/Wakbu/weavexdr/releases)에서 최신 Windows ZIP을 내려받습니다.
2. ZIP의 압축을 새 폴더에 풉니다. 압축 파일 안에서 EXE를 바로 실행하지 마세요.
3. `WeaveXDR.exe`를 실행합니다.
4. 잠시 뒤 브라우저에 대시보드가 자동으로 열립니다. 비밀번호나 토큰을 직접 입력할 필요는 없습니다.
5. 처음에는 **보안 개요**에서 보호 상태와 최근 사건 수를 확인합니다.
6. 사건이 있으면 **사건 → 조사** 순서로 들어가 근거와 관계도를 확인합니다.

브라우저가 열리지 않으면 EXE를 완전히 종료하고 다시 실행하세요. 주소창에 대시보드 주소부터 직접 입력하면 자동 보안 연결이 성립하지 않을 수 있습니다. 자세한 복구 방법은 [설치·운영·복구 안내](docs/OPERATIONS.md)를 참고하세요.

## 화면은 이렇게 읽으면 됩니다

### 보안 개요

현재 PC의 전체 상태를 빠르게 보는 첫 화면입니다.

- **전체 사건**: 저장된 사건의 총개수
- **고위험**: 빨리 확인하는 것이 좋은 사건
- **검토 필요**: 정상인지 위험한지 추가 확인이 필요한 사건
- **3D 지구본**: 최근 수상한 네트워크 징후가 연결된 국가와 사건 수
- **공격 관계도**: 가장 최근 사건의 프로그램·파일·외부 연결 흐름

숫자가 많다고 모두 감염된 것은 아닙니다. 자동화 도구나 관리 스크립트도 수상한 명령을 사용할 수 있으므로 반드시 근거를 함께 확인하세요.

### 사건

여러 보안 기록을 하나로 묶은 조사 목록입니다. 위험 점수, 판정, 주요 증거와 발생 시각으로 정렬·검색할 수 있습니다.

- **고위험**: 여러 강한 근거가 모였거나 위험도가 높은 행동
- **검토 필요**: 단서가 있지만 정상 행위일 가능성도 있는 상태
- **정상**: 현재 규칙으로는 위험 근거가 충분하지 않은 상태

### 조사

선택한 사건을 자세히 살펴보는 곳입니다.

- 점은 PC, 프로그램, 파일, IP 주소 같은 대상입니다.
- 선은 실행, 생성, 접속 같은 관계입니다.
- 실선은 직접 관찰한 관계, 점선은 여러 증거로 추정한 관계입니다.
- 선을 누르면 그 관계를 만든 원본 이벤트를 확인할 수 있습니다.
- 1~3홉 보기는 선택한 점에서 가까운 관계만 남깁니다.
- 최단 공격 경로는 외부 연결부터 파일·지속성까지 이어지는 가장 짧은 흐름을 강조합니다.
- 관계 인텔리전스는 희귀 관계, 시간대별 활동, 가능한 가설과 부족한 증거를 보여 줍니다.

마우스 휠로 확대·축소하고 빈 공간을 드래그해 이동할 수 있습니다. 계층형, 방사형, 시간축, 힘 기반 배치를 즉시 바꿀 수 있습니다.

### 파일 검사

검사할 파일이나 폴더를 선택해 수동으로 확인합니다. 직접 경로를 외워 입력할 필요가 없습니다.

- **빠른 검사**: 자주 악용되는 위치를 우선 확인
- **전체 검사**: 더 넓은 범위를 검사하므로 오래 걸릴 수 있음
- **사용자 지정**: 내가 고른 파일·폴더만 검사
- **격리**: 수상한 파일을 바로 삭제하지 않고 안전한 위치로 옮겨 실행을 막음

검사 결과만 보고 중요한 파일을 영구 삭제하지 마세요. WeaveXDR은 복구 가능한 격리를 우선합니다.

### 운영 관리·AI 모델·탐지 콘텐츠·설정

- **운영 관리**: 업데이트, 백업, 복구, 보고서와 실제 대응 기능
- **AI 모델**: 내 PC 사양에 맞는 로컬 모델 설치·선택과 상태 확인
- **탐지 콘텐츠**: 어떤 규칙으로 수상한 행동을 찾는지 확인하고 후보 규칙을 안전하게 시험
- **설정**: 자동 실행, 수집과 화면 표시처럼 프로그램 동작 방식 변경

정보 밀도는 단순한 글자 크기 조절이 아닙니다. **간단히**는 핵심 판정 위주, **기본**은 일반 설명 포함, **조밀하게**는 설명을 줄여 더 많은 항목 표시, **상세**는 사건 ID·규칙·관계 근거까지 표시합니다.

## 로컬 AI는 무엇을 하나요?

오른쪽 아래의 Weave AI에게 다음처럼 물어볼 수 있습니다.

- “지금 가장 먼저 확인할 사건은?”
- “이 두 노드가 왜 연결됐어?”
- “가능한 공격 가설과 부족한 증거를 알려줘.”
- “이 사건의 위험 근거를 초보자도 이해하게 설명해줘.”

AI 답변은 조사 보조 설명입니다. 최종 위험 점수는 검증 가능한 규칙이 계산하고, 파일 격리·프로세스 종료·네트워크 차단은 대상 재확인과 사용자 승인 없이는 실행하지 않습니다. 모델이 없거나 응답하지 않아도 규칙 기반 핵심 기능은 계속 동작합니다.

## 안전 원칙

- AI 판단만으로 파일을 영구 삭제하지 않습니다.
- 실제 대응 전 대상이 여전히 같은 파일·프로세스인지 다시 확인합니다.
- 격리와 차단에는 복구 기록을 남깁니다.
- 대시보드 API는 기본적으로 내 PC의 `127.0.0.1`에만 열립니다.
- 업데이트 적용 전 패키지 해시와 내부 파일을 검증하고 DB 백업을 만듭니다.
- 보고서를 내보낼 때 사용자 경로 등 민감한 정보를 가릴 수 있습니다.

## 문제가 생겼을 때

- **화면이 열리지 않음**: EXE를 종료한 뒤 다시 실행합니다.
- **연결 오류**: 예전에 열어 둔 탭을 닫고 새로 열린 탭을 사용합니다.
- **실시간 수집 안 됨**: 설정에서 Sysmon과 관리자 권한 안내를 확인합니다.
- **AI 답변 안 됨**: AI 모델 화면에서 Ollama와 선택 모델 상태를 확인합니다. 보안 탐지 자체는 계속 동작합니다.
- **파일 검사 중단**: 현재 검사가 완료·취소됐는지 확인한 뒤 새 경로를 선택합니다.
